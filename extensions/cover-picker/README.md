# MyLists Cover Picker

Send a cover from Google Images to MyLists with a right-click.

## Install in Brave

1. Open `brave://extensions` and turn on **Developer mode**.
2. Click **Load unpacked** and select `extensions/cover-picker`.
3. Reload MyLists.

## Use

1. Open a book’s cover dialog, **Edit details**, or **Administration → Missing covers**.
2. Click **Search Google Images**.
3. Open a large image, right-click it, and choose **Use as MyLists cover**.
4. Back in MyLists, check the cover and save.

Your account must have permission to save the cover.
Start each search from MyLists. Use the large image, not its thumbnail.

Works on `mylists.info`, `localhost`, and `127.0.0.1`.
After an extension update, reload it at `brave://extensions`, then reload MyLists.
